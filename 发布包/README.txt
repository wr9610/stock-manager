  进销存系统 StockManager v1.0（单机版）
═══════════════════════════════════════════════

【系统要求】
  · Windows 10 / 11 64位
  · 不需要安装任何软件、不需要联网

【怎么用】
  1. 把整个「发布包」文件夹拷到你电脑上（任意位置）
  2. 双击 StockManager.App.exe 启动
  3. 默认账号 admin / 密码 admin123（进去后可改）
  4. 建议把程序固定在任务栏，收银台扫码枪一插就能用

【数据在哪】
  程序同目录 data\stock.db 就是你的全部数据
  ⚠ 备份 = 复制这个文件走（设置页里也有备份按钮）

【试用说明】
  · 首次启动开始算 15 天全功能试用
  · 到期后自动进入只读模式（能查历史、能备份，不能新增业务）
  · 喜欢就用，想激活联系作者

───────────────────────────────────────────────
常见问题
───────────────────────────────────────────────
Q：扫码枪扫不出来？
A：确认扫码枪是「键盘模拟模式」（默认），串口模式需驱动。

Q：打印机怎么配？
A：58mm 热敏小票机。USB的装驱动后选串口模式；
   网络版选网络模式填IP。设置页有「打印测试页」。

Q：钱算得准吗？
A：金额一律按「分」存储计算，不存在浮点误差；
   库存成本用移动加权平均，业界标准算法。

Q：数据会不会丢？
A：SQLite 默认 WAL + 每次写全同步（断电不丢已提交数据）；
   建议每天设置页备份一次。
